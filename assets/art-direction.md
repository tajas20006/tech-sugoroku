# 2D アートディレクション

## 目標

子どもから AWS 初学者まで遊びやすい、明るいクラウドテーマの 2D ボードゲームにする。専門用語が多くなりすぎないよう、サービスそのものではなく「雲・コイン・サーバー・盾・稲妻」を中心としたゲーム用の視覚表現を用いる。

## 推奨する素材の用意方法

初期版は、以下を組み合わせる。

| 素材 | 用意方法 | 理由 |
| --- | --- | --- |
| 盤面のマス、枠、文字 | Flet の UI 部品で描画 | 状態や色を動的に変更しやすい。 |
| 背景 | 1 枚のオリジナル 2D イラスト | 盤面全体に統一感を出せる。 |
| プレイヤートークン | 小さなオリジナル PNG 素材 | 色違い・状態違いを作りやすい。 |
| アイテム | 同じタッチの PNG アイコン | 何を持っているかを一目で伝えられる。 |
| 演出 | Flet の拡大、移動、透明度アニメーション | GIF や動画を増やさず、実装を軽く保てる。 |

背景、トークン、アイテムは生成画像で作る方法が最も速い。生成時は個別に作るのではなく、共通の色・線・陰影を指定して、同じアートスタイルのセットとして作成する。必要に応じて、後からデザイナー制作の素材に差し替えられるよう、ファイル名とサイズを固定する。

## ビジュアルルール

- テイスト: フラット寄りの 2D イラスト、太めの輪郭、やわらかい影、丸い形。
- 配色: 空色、ネイビー、白を基調に、緑・紫・オレンジ・赤・金をアクセントに使う。
- 背景: 明るい雲、浮遊する小島、データセンター、ネットワーク線。文字や細かい記号は入れない。
- アイコン: 64 または 128 px の正方形。透明背景。外周に余白を取り、小さく表示しても判別できる形にする。
- トークン: 96 px 四方の透明背景。プレイヤー色を変えても顔・輪郭のデザインは共通にする。
- アクセシビリティ: 色だけでマス種別を伝えず、必ず記号またはアイコンも併用する。

## 生成用プロンプトの指針

背景には、次のような方向性を指定する。

> 明るくポップな 2D ボードゲーム用背景。青空と白い雲の上に、浮遊する小島、かわいいデータセンター、ネットワーク線、コインを少し配置する。フラット寄りのイラスト、太い丸い輪郭、やわらかい影。文字、ロゴ、数字、UI は入れない。横長 16:9。

アイテムには、次の共通指定を付ける。

> ポップな 2D ボードゲームのアイテムアイコン。太い丸い輪郭、フラットな塗り、やわらかい影、透明背景、中央配置、文字やロゴなし、64px でも識別できるシンプルな形。

各アイテムのモチーフは、WAF は青いエネルギーシールド、DDoS は赤いパケットの波、AWS Backup はクラウド付きの金庫、Multi-AZ は二つの拠点を結ぶ盾、Auto Scaling は上下矢印付きのサーバーとする。

## 避けること

- AWS の公式ロゴやサービスアイコンを、ゲームのキャラクター・装飾として無断で加工して使わない。
- 背景画像に盤面のマスやテキストを焼き込まない。盤面変更が難しくなる。
- アイテムごとに異なる絵柄や解像度を混在させない。
- 情報を画像だけに閉じ込めない。効果は常にテキストでも表示する。
